# Управление светом через релейные платы (Django)

Веб-приложение для управления двухканальными релейными платами по сети (TCP). Позволяет включать/выключать свет, отслеживать состояние плат и реле, а также работать по расписанию с автоматической синхронизацией.

## Возможности

- Добавление, редактирование и удаление плат реле (каждая плата — два канала).
- Ручное включение/выключение каждого реле.
- Массовое включение/выключение всех реле на всех платах.
- Проверка доступности плат и актуальных состояний реле (одной кнопкой).
- Настройка единого расписания включения/выключения света (время включения, время выключения, учёт перехода через полночь).
- Ручная и автоматическая синхронизация реле по расписанию (cron/django-crontab каждые 10 минут).
- Автоматическое восстановление связи с платами после их временного отключения.
- Аутентификация пользователей (вход по логину/паролю).

## Требования

- Python 3.8+ (или Docker / Docker Compose)
- Django 4.2+ (рекомендуется)
- Платы реле, доступные по TCP на порту 6722 (стандартный, можно изменить в коде)
- Опционально: `django-crontab` для автоматической синхронизации по расписанию

## Установка и настройка

### Вариант 1. Запуск через Docker Compose (Рекомендуется)

1. Клонируйте репозиторий:

   ```bash
   git clone <url-репозитория>
   cd light_control
   ```

2. Запустите контейнеры:

   ```bash
   docker compose up --build -d
   ```

3. Выполните миграции базы данных:

   ```bash
   docker exec -it relay-web python manage.py migrate
   ```

4. Создайте суперпользователя для входа в веб-интерфейс:

   ```bash
   docker exec -it relay-web python manage.py createsuperuser
   ```

5. Откройте браузер и перейдите на `http://localhost:8000`. Войдите под созданными учётными данными.

### Вариант 2. Локальная установка (без Docker)

1. Клонируйте репозиторий:

   ```bash
   git clone <url-репозитория>
   cd light_control
   ```

2. Создайте и активируйте виртуальное окружение:

   ```bash
   python -m venv venv
   source venv/bin/activate  # Linux/Mac
   venv\Scripts\activate   # Windows
   ```

3. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

   Если `requirements.txt` отсутствует, установите вручную:

   ```bash
   pip install django django-crontab
   ```

4. Выполните миграции базы данных:

   ```bash
   python manage.py migrate
   ```

5. Создайте суперпользователя для входа в веб-интерфейс:

   ```bash
   python manage.py createsuperuser
   ```

6. Запустите сервер разработки:

   ```bash
   python manage.py runserver 0.0.0.0:8000
   ```

7. Откройте браузер и перейдите на `http://<ip-сервера>:8000`. Войдите под созданными учётными данными.

## Использование

### Управление платами и реле

- **Главная страница** — таблица со всеми платами, их доступностью и кнопками управления реле.
- **Добавить плату** — кнопка «Добавить плату». Укажите IP-адрес, описание, расположение и названия для каждого реле (какую лампу включает). Плата сразу проверяется на доступность.
- **Редактировать/удалить** — ссылки в последнем столбце таблицы.
- **Обновить все платы** — проверяет доступность и обновляет состояния реле для всех плат.
- **Включить всё / Выключить всё** — массовое управление всеми реле на доступных платах.
- **Синхронизировать по расписанию** — вручную приводит состояния реле в соответствие с текущим временем и настройками расписания.

### Расписание

Перейдите по кнопке **«⚙ Расписание»**. Здесь можно:

- Включить/отключить расписание.
- Задать время включения и выключения (формат ЧЧ:ММ).
- Включить автоматическую синхронизацию каждые 5 минут (требует настройки cron, см. ниже).

Если расписание активно и автосинхронизация включена, специальная команда будет каждые 5 минут проверять время и включать/выключать свет. При ручной синхронизации проверка происходит однократно.

### Принцип работы с платами

Приложение отправляет TCP-команды на плату (порт 6722). Протокол:

- `'11'` — включить реле 1
- `'12'` — включить реле 2
- `'21'` — выключить реле 1
- `'22'` — выключить реле 2
- `'00'` — запрос состояния (ничего не меняет)

Ответ платы содержит 2 символа: первый — состояние реле 1 (1 — вкл, 0 — выкл), второй — реле 2. Пример: `'10'` означает «реле 1 включено, реле 2 выключено».

#### Поведение при недоступности

Если плата не отвечает (выключена, обрыв сети), она помечается как «Недоступна». При следующей попытке управления (ручной или автоматической) происходит проверка связи. Как только плата снова отвечает, она становится доступной и выполняет требуемые команды.

### Настройка автоматической синхронизации (cron)

Чтобы расписание работало без участия человека, настройте периодический запуск management-команды `sync_schedule`. Есть основные способы:

#### При запуске через Docker Compose

В `docker-compose.yml` настроен отдельный контейнер `relay-cron`, который автоматически запускает `django-crontab` в общем окружении с веб-приложением.

#### Через системный cron (без Docker и без django-crontab)

Добавьте в crontab (команда `crontab -e`) строку:

```bash
*/5 * * * * cd /полный/путь/к/проекту && /путь/к/виртуальному/окружению/bin/python manage.py sync_schedule >> /путь/к/логу/sync_schedule.log 2>&1
```

#### Через django-crontab (без Docker)

1. Убедитесь, что `django-crontab` установлен и добавлен в `INSTALLED_APPS`.
2. В `settings.py` пропишите задания:

   ```python
   CRONJOBS = [
       ('*/5 * * * *', 'boards.cron.sync_schedule_cron', '>> /tmp/sync_schedule.log 2>&1'),
   ]
   ```

3. Зарегистрируйте задания:

   ```bash
   python manage.py crontab add
   ```

   Для удаления заданий: `python manage.py crontab remove`.

Команда `sync_schedule` проверяет флаг `auto_sync_enabled` в настройках расписания. Если он снят, команда не производит переключений, даже если cron её запускает. Это позволяет гибко управлять автоматикой через веб-интерфейс.

## Безопасность

- Доступ ко всем функциям приложения разрешён только аутентифицированным пользователям.
- Используйте сложные пароли.
- В production-окружении настройте HTTPS и отключите `DEBUG = False`.
- При необходимости ограничьте доступ к порту 6722 на файрволе только для сервера приложения.

## Дополнительно

Приложение разработано для управления светом, но может быть адаптировано для любых устройств, управляемых аналогичными релейными платами. Функция `send_signal` легко заменяется на любой другой протокол связи.
